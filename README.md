# Goldutya Fly

Flap the Goldutya duck through the pipes. Quack survival.

Vanilla HTML5 canvas game — zero dependencies, no build step. Deploy anywhere (Vercel, Netlify, GitHub Pages).

## Play

Open `index.html` in a browser, or run a static server:

```bash
npx serve .
```

Controls: tap / click / space / up-arrow to flap.

## Deploy to Vercel

```bash
vercel --prod
```

Or import this repo in the Vercel dashboard (Framework Preset: Other / Static).
